## Sobre o Projeto
Aplicativo mobile desenvolvido em React Native com foco na segurança de mulheres em situação de vulnerabilidade, utilizando um disfarce funcional de bloco de notas e uma área restrita de apoio rápido, contactos de emergência e diário sigiloso.
